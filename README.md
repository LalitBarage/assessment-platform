# Nexanova Assessment Platform

This is the assessment platform project containing both backend and frontend applications.

## Prerequisites

- Node.js (v18+)
- MongoDB

## Setup Instructions

1. **Environment Variables**: 
   Copy `.env.example` to `.env` in the root/backend folder and fill in the appropriate values.
   ```bash
   cp .env.example backend/.env
   ```

2. **Backend Setup**:
   ```bash
   cd backend
   npm install
   npm run dev
   ```

3. **Frontend Setup**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
